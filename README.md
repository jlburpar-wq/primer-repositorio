¿Que es github? github es una plataforma en la nube que permite a los desarrolladores almacenar,
gestionar y colaborar en proyectos de código fuente utilizando el sistema de control de versiones git.

¿Que espero aprender al utilizar repositorios? yo espero aprender conceptos esenciales, así como a
crear espacios de trabajos (locales o remotos) donde se almacena todo el historial y los archivos de
mis proyectos
